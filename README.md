# Material Boot Core

The code shared by [Material GRUB](https://github.com/LucaCraft89/material-grub) and Material Plymouth: colour palettes, the distro catalog, the overrides and conf formats, and the scene renderer.

**Status: empty on purpose.** The code moves here only after Material Plymouth works (phase 8 of the plan in material-grub/docs/plans/plymouth.md). Nothing here is usable yet.
