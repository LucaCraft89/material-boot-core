# Material Boot Core

The code shared by [Material GRUB](https://github.com/LucaCraft89/material-grub) and [Material Plymouth](https://github.com/LucaCraft89/material-plymouth): colour palettes, the distro catalog, the overrides and conf formats, the scene renderer, the safety and upgrade machinery, and the `material-boot` command that parts plug into.

**Status: version 1.0.0, [released](https://github.com/LucaCraft89/material-boot-core/releases/tag/v1.0.0)** together with Material GRUB and Material Plymouth. The release attaches the bundle (`material-boot-1.0.0.tar.gz`): one installer for the core and both parts, see its notes. The agreed shape is in [docs/architecture.md](docs/architecture.md).
